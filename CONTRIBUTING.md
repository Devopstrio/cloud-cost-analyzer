# Contributing to Cloud Cost Analyzer

Thank you for contributing to the **Cloud Cost Analyzer** SDK!

## Development Workflow

1. Fork & clone the repository.
2. Install dependencies: `npm install`
3. Create a feature branch: `git checkout -b feat/my-analytics-feature`
4. Write tests for new SDK functionality in `tests/`.
5. Run test suite: `npm test`
6. Submit a Pull Request.
