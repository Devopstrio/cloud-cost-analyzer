# Getting Started Guide: Cloud Cost Analyzer

Welcome to **Cloud Cost Analyzer**. This guide provides step-by-step instructions for installation, TypeScript compilation, and running tests.

## Prerequisites

- Node.js `>= 20.0.0`
- npm `>= 10.0.0`
- OpenTofu `>= 1.6.0` or Terraform `>= 1.6.0`

## Local Installation

```bash
# Clone the repository
git clone https://github.com/Devopstrio/cloud-cost-analyzer.git
cd cloud-cost-analyzer

# Install dependencies
npm install

# Build TypeScript SDK
npm run build

# Run unit and integration tests
npm test
```
